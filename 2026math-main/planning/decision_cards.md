## Q1 决策卡

| 比较项 | A 事件驱动连续优化 | B 解析构造 baseline | C 区间全局集合反演 |
|---|---|---|---|
| 题目覆盖完整度 | 高：可行/不可行均有输出 | 中高：受限族完整 | 高：全局可行域 |
| 数学正确性 | 高，需区间复核 | 高且透明 | 理论高，依赖正确包络 |
| 可解释性 | 高 | 很高 | 中 |
| 预期精度 | 高 | 中 | 高 |
| 稳健性 | 中高 | 中 | 高 |
| 创新潜力 | 高：探测事件+圆盘覆盖证书 | 中 | 高 |
| 编程难度 | 中 | 低 | 高 |
| 论文难度 | 中 | 低 | 高 |
| 最大风险 | 自然解释下硬约束无解/局部性 | 受限族漏解 | 维数灾难 |
| 所需时间 | 0.5–1 天 | 2–4 小时 | 1–2 天 |
| baseline 有效性 | 需 B | 是 | 仍需 B |
| 当前推荐等级 | **推荐，条件性** | 必须保留 | 触发式备用 |

- 推荐：A，B 同时作为 baseline。
- 推荐理由：A 最贴合连续探测窗口和完整圆盘遮蔽，能合法处理“无解”；B 提供解析上界和可解释对照。
- 当前最大风险：持续锁定从 8 km 开始时，单弹覆盖时长上界不足。
- 仍缺证据：三主体初态、导弹追踪律、干扰弹/云心运动。
- 下一步最小验证实验：补一组完整场景，A/B 同时计算探测窗口和最小覆盖裕度，并用独立细网格复核。
- 通过标准：所有输入有来源；连续约束零违反；事件法与独立复核的成败一致、边界时间差在预先设定的数值容差内。
- 验证失败后：若因局部性/证书不足切 C；若物理时长严格不足，不切换算法，报告不可行并等待你授权次级目标。
- 你真正需要判断：你是否接受“严格无解证书”作为 Q1 的正式结论；若接受最佳可达次级输出，必须由你明确授权。

`decision_id: q1_method_choice`

- A：采用事件驱动连续优化，承担中等实现工作，优先获得连续证书。
- B：只采用解析构造，换取透明和低风险，但不声称全局。
- C：采用区间全局反演，换取最强证书，承担较高时间风险。

## Q2 决策卡

| 比较项 | A 覆盖区间图+动态规划 | B 刚好接续 baseline | C 时间扩展 MILP |
|---|---|---|---|
| 题目覆盖完整度 | 高 | 高（构造族） | 高 |
| 数学正确性 | 高，结构贴题 | 高且直观 | 中高，需连续复核 |
| 可解释性 | 高 | 很高 | 中 |
| 预期精度 | 高 | 中 | 高（离散误差受控时） |
| 稳健性 | 高，可显式留交叠 | 中 | 中高 |
| 创新潜力 | 高 | 中 | 中 |
| 编程难度 | 中 | 低 | 中高 |
| 论文难度 | 中低 | 低 | 中高 |
| 最大风险 | 候选节点遗漏 | 贪心可达死锁 | 伪连续/大 M |
| 所需时间 | 0.5–1 天 | 2–4 小时 | 约 1 天 |
| baseline 有效性 | 需 B | 是 | 仍需 B |
| 当前推荐等级 | **推荐，条件性** | 必须保留 | 结构困难时备用 |

- 推荐：A。
- 推荐理由：最多三弹使区间图深度很小，既比通用 MILP 更贴题，又比刚好接续规则更有全局改进空间。
- 当前最大风险：真实节点生成取决于无人机初态和烟幕中心运动。
- 仍缺证据：真实可达节点、连续空档复核、对 B 的增益。
- 下一步最小验证实验：在一组完整单机场景生成所有单弹覆盖区间，求 A/B 三弹链并做事件级无缝检查。
- 通过标准：A 不劣于 B；所有投放可达；连续覆盖无负裕度；时间/位置小扰动后的最小交叠非负或有明确触发阈值。
- 验证失败后：节点生成结构失效或漏解时切 C；若 A 无显著增益则回退 B。
- 你真正需要判断：你更看重结构最优与可解释平衡（A），还是极简可靠规则（B）；C 只用于复杂逻辑。

`decision_id: q2_method_choice`

- A：区间图/动态规划主方案。
- B：构造式主方案。
- C：时间扩展 MILP 主方案。

| baseline 有效性 | 需 B | 是 | 仍需 B |
| 当前推荐等级 | **推荐，条件性** | 必须保留 | 有误差数据时备用 |

- 推荐：A。
- 推荐理由：严格保持防御成功优先，可用 Pareto 展示覆盖、冗余和能耗而不伪造权重，且留一失效与题目高度匹配。
- 当前最大风险：安全距离、能耗函数、烟幕叠加定义均未给。
- 仍缺证据：真实 Pareto 点、全航程最小机间距、留一增益。
- 下一步最小验证实验：给定三机初态与 `d_safe`，穷举 B 的 3! 匹配并与 A 的候选组合比较，同时做三次留一失效。
- 通过标准：防御硬约束与安全距离零违反；A 至少在一个次级指标严格优于 B 且其他一级指标不劣；留一结果可复现。
- 验证失败后：A 无增益则用 B；名义方案对有依据的扰动脆弱时切 C。
- 你真正需要判断：是否接受用路径长/转向作为能耗代理，以及烟幕重叠只解释为几何覆盖/冗余而非光学增厚。

## Q4 决策卡

| 当前推荐等级 | **推荐，条件性** | 必须保留/实时备用 | 暂不启用 |

- 推荐：A，B 作为实时超时备用。
- 推荐理由：A 将威胁层级、可达弧、时间窗和五机十五弹资源流统一，避免“先评分、后发现不可执行”。
- 当前最大风险：没有任何真实导弹批次或五机状态。
- 仍缺证据：真实规模、重算时间、三工况、对 B 的后悔优势。
- 下一步最小验证实验：提供一张小型事件表，构造资源充足/临界/短缺三个子集，A/B 同跑并由小规模穷举复核。

- 验证失败后：运行超时立即切 B；只有存在可信误差数据且名义解尾部失效时切 C。
- 你真正需要判断：资源短缺时采用何种人类风险偏好——优先最大化高威胁防御数量、最小总未防御风险，还是保留应急弹药；当前不能由 AI 替你定。
