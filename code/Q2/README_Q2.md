# 问题二：单机多弹连续遮蔽程序

## 范围

本目录只实现 Q2 编程手工作。主方案是“共线烟幕圆盘并集连续优化模型”，
使用 G1/S1/O0/U0 相对模型；B 是强制保守 baseline。程序不修改 Q1，不实现
Q3/Q4，也不把三弹结果表述为全局最优。

## 核心判据

固定时刻对舰船相对横坐标 `xi in [-R_s,R_s]`，每团烟幕给出一条一次函数
`L_j(xi,t)`。程序解析检查区间端点和两两交点，计算
`G_union(t)=min_xi max_j L_j(xi,t)`；`G_union>=0` 当且仅当共线烟幕圆盘并集
完整覆盖舰船圆盘。`G_union` 单位为平方米，不是距离裕度。

连续结论由物理事件/结构事件分段、解析根与保守时间盒给出。高密度时间扫描只用于
发现实现错误，不作为连续证明。

## 运行

使用包含 NumPy、SciPy、pandas、Matplotlib 与 pytest 的 Python：

```powershell
<PYTHON> code/Q2/q2_run_round2.py --all
```

开发测试在正式交付前执行并删除；生产入口不调用 pytest，也不依赖 `tests/`。

## 结论边界

- 允许锁定前预警部署时，两弹规范计划覆盖 G1 最坏窗口。
- 若命令只能从锁定时刻开始，最初 5.5 s 必然裸露。
- 一弹上界是解析精确结论；两弹在结构归一化下以桥接切触根和末端衰减根联合
  精修。由于高精度根仍比从工作文档动态读取的参考值略短，正式强度为
  `best_verified_two_bomb_collinear_solution`，不再称为已验证能力前沿，也不
  宣称任意二维全局最优；三弹仅为当前最佳已验证共线方案。
- 鲁棒性搜索范围均为探索性范围。若扫描边界处仍可行，JSON 将该方向标为
  `scan_censored_* = true`，不会把测试边界冒充真实失效阈值。
- 未覆盖面积的 `0` 来自固定时刻必要充分截面判据；Decimal 积分仅作 60/120 位
  精度加倍诊断，不再人为添加 `1e-30` guard，也不对负值作事后夹零。
- 缺少无人机绝对初态和基地基准，因此绝对首投点、12 km 绝对可达性保持 blocked。
- 当前原题与 Q1 历史记录的哈希来源差异见
  `results/Q2/reports/q2_source_document_provenance.json`。
