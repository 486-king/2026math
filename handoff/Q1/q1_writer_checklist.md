# Q1 论文手工作清单

## 推荐章节逻辑

论文叙事必须采用：**硬约束可行性检查 → 全局不可行证明 → 最优补偿方案 → 稳健性与扩展**。

## 需要写清的内容

- [ ] 定义舰船、导弹、干扰弹和烟幕的二维运动。
- [ ] 明确 M1、S1 和完整圆盘遮蔽判据。
- [ ] 解释为什么“烟幕存在 23 s”不等于“完整遮蔽 23 s”。
- [ ] 推导固定烟幕允许中心偏差 `120-80=40 m`。
- [ ] 推导单弹最大连续完整遮蔽 `80/7.71=10.3761 s`。
- [ ] 推导 M1 距离变化率界和探测窗口下界 `24.1677 s`。
- [ ] 得出至少 `13.7916 s` 裸露时间，并明确全程遮蔽严格不可行。
- [ ] 说明 A、B、C 一致，C 排除了局部最优和舍入误差。

## 不可行后的补偿方案

- [ ] 定义 `h=(R_c-R_s)/V_s=5.1881 s`。
- [ ] 给出长度最优云心族 `c*=s(t_c)`。
- [ ] 给出 `t_c∈[t_in+h,t_out-h]`。
- [ ] 给出起爆区间 `t_b∈[t_c+h-18,t_c-h]`。
- [ ] 给出投放关系 `t_d=t_b-3.5`、`p_d=c*-98e_u`。
- [ ] 说明达到 10.3761 s 上界的五项条件。
- [ ] 若强调防御稳定性，采用时间居中解，使两端不可避免裸露段相等。
- [ ] 若强调尽早保护，给出从 `t_in` 开始的代表解。

## 表述边界

- [ ] 写“在 M1/S1 和题面常数下严格不可行”，不要写成无条件普遍结论。
- [ ] 写“全局可行集为空”，不要写“算法没有搜到解”。
- [ ] 不提供虚构的绝对投放坐标。
- [ ] 将 M2 和烟幕漂移列为扩展，不把缺数据包装成已完成验证。
- [ ] 不宣称保证奖项或绝对最优战术效果。
